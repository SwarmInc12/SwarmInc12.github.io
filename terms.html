What the products are

SwarmInc publishes small data tools: JSON APIs sold through RapidAPI (7 public) and Actors on the Apify Store (8 public). Each reads a public data source at call time and returns rows as JSON. Each product's page says what it returns, its parameters and its fields, shows rows from its own test run, and names and credits the source it reads. The data sources are public; each product's page credits its own.
