EU Public Tender Monitor (TED)

New public procurement notices from the EU's official TED search API for a CPV code prefix, buyer country and keyword, returning only the notices that are new …

This Actor collects public data from TED, the EU's official journal of public procurement, through its official search API v3 (no key needed). You give it a CP…

Run it on the Apify Store  $1.60 per 1,000 results, billed by Apify; Apify's free plan includes monthly credit.

Inputs

FieldTypeWhat it doesExample
cpv_prefixstringCPV code prefix: Start of the CPV code to follow (for example 72 for IT services, 45 for construction, 33 for medical equipment)."72"
countrystringBuyer country: Country of the buying organisation, as a three-letter ISO code."FRA"
keywordstringKeyword in the title: Optional word that the notice title must contain. Leave empty to keep all notices."services"
published_sincestringPublished since: Only notices published on or after this date, written YYYYMMDD."20250101"
onlyChangesbooleanOnly changes: On: each run returns only the records whose watched values changed since your last run (your first run returns them all). Off: every matching record, each with…false
maxItemsintegerMax results: Stop after this many results (keeps a run's cost predictable).5000

Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-ted-tender-monitor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"country": "FRA", "cpv_prefix": "72", "keyword": "services", "maxItems": 5000, "onlyChanges": false, "published_since": "20250101"}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/store-ted-tender-monitor").call(run_input={'country': 'FRA',
 'cpv_prefix': '72',
 'keyword': 'services',
 'maxItems': 5000,
 'onlyChanges': False,
 'published_since': '20250101'})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

From an AI agent: connect Apify's MCP server and add the Actor nonstop_poacher/store-ted-tender-monitor.
