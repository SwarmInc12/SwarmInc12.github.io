French Company Search (Recherche d'entreprises, Sirene)

Search France's official company register by NAF activity code, département, headcount band and status, and get typed legal-entity records with head-office add…

This Actor pulls public data on French companies from the State's official Recherche d'entreprises API (INSEE Sirene register, credited to recherche-entreprise…

Run it on the Apify Store  $0.80 per 1,000 results, billed by Apify; Apify's free plan includes monthly credit.

Inputs

FieldTypeWhat it doesExample
activite_principalestringNAF activity code: Main activity code (NAF rev. 2) of the company, e.g. 62.01Z (computer programming), 56.10A (restaurants), 47.11D (supermarkets)."62.01Z"
departementstringDépartement: Département code of the head office, e.g. 75 Paris, 69 Rhône, 2A Corse-du-Sud. Leave empty for all of France."75"
tranche_effectif_salariestringHeadcount band code: INSEE headcount band: 00 (0), 01 (1-2), 02 (3-5), 03 (6-9), 11 (10-19), 12 (20-49), 21 (50-99), 22 (100-199), 31 (200-249), 32 (250-499), 41 (500-999), 42 (100…"11"
etat_administratifstringStatus: A = active companies, C = ceased companies."A"
maxItemsintegerMax results: Stop after this many results (keeps a run's cost predictable).5000

Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-fr-company-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"activite_principale": "62.01Z", "departement": "75", "etat_administratif": "A", "maxItems": 5000, "tranche_effectif_salarie": "11"}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/store-fr-company-search").call(run_input={'activite_principale': '62.01Z',
 'departement': '75',
 'etat_administratif': 'A',
 'maxItems': 5000,
 'tranche_effectif_salarie': '11'})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
