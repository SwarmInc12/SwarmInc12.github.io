Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~apify-google-sheets-alt/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"maxPages": 20, "proxyConfiguration": {"useApifyProxy": true}, "startUrls": [{"url": "https://docs.google.com/spreadsheets/d/1XWJLkAwch5GXAt_7zOFDcg8Wm8Xv29_8PWuuW15qmAE/export?format=csv&gid=0"}]}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/apify-google-sheets-alt").call(run_input={'maxPages': 20,
 'proxyConfiguration': {'useApifyProxy': True},
 'startUrls': [{'url': 'https://docs.google.com/spreadsheets/d/1XWJLkAwch5GXAt_7zOFDcg8Wm8Xv29_8PWuuW15qmAE/export?format=csv&gid=0'}]})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
