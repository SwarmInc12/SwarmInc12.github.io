Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-clinical-trials-monitor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"condition": "breast cancer", "maxItems": 5000, "onlyChanges": false, "phase": "PHASE2", "status": "RECRUITING", "updated_since": "2025-01-01"}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/store-clinical-trials-monitor").call(run_input={'condition': 'breast cancer',
 'maxItems': 5000,
 'onlyChanges': False,
 'phase': 'PHASE2',
 'status': 'RECRUITING',
 'updated_since': '2025-01-01'})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
