Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-internet-archive/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"maxItems": 2000, "query": "collection:prelinger"}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/store-internet-archive").call(run_input={'maxItems': 2000, 'query': 'collection:prelinger'})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

From an AI agent: connect Apify's MCP server and add the Actor nonstop_poacher/store-internet-archive.
