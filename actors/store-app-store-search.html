Inputs

termstringSearch term: Keyword to search for in the App Store (for example budget, photo editor, meditation)."budget"
countrystringStorefront country: Two-letter App Store country code, which sets the prices, currency and ratings returned."us"
limitintegerMaximum apps: How many apps to return (Apple allows up to 200 per search).50
maxItemsintegerMax results: Stop after this many results (keeps a run's cost predictable).200

First call in 60 seconds

  1. Get an Apify token (the Store page; Apify's free plan includes monthly credit)

  2. Run one call with the example input (the Apify API):

    curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-app-store-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"country": "us", "limit": 50, "maxItems": 200, "term": "budget"}'

Call it from code

With the Apify API (one request; the response is the results):

curl -X POST "https://api.apify.com/v2/acts/nonstop_poacher~store-app-store-search/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"country": "us", "limit": 50, "maxItems": 200, "term": "budget"}'

With the Python client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("nonstop_poacher/store-app-store-search").call(run_input={'country': 'us', 'limit': 50, 'maxItems': 200, 'term': 'budget'})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
