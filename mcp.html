Open data tools for AI agents (MCP)

An MCP server with 7 official open-data tools: App Store App Search (iTunes API): prices, ratings, versions by country, ClinicalTrials.gov Study Monitor, Bulk .com domain registration check via RDAP, EU Fuel Price Change Monitor (France, Spain), F. Remote, streamable HTTP; your own RapidAPI key.

Server URL: https://api.gregswarm.duckdns.org/mcp
Registry name: org.duckdns.gregswarm.api/open-data (the official MCP registry)

Get a free RapidAPI key  each tool call goes through RapidAPI with your key, counted on your plan; the free plan has 50 requests a month. Send the key as X-RapidAPI-Key, X-API-Key or Authorization: Bearer. Listing the tools needs no key.

Add it to your agent

Claude Code:

claude mcp add --transport http open-data https://api.gregswarm.duckdns.org/mcp \
  --header "X-RapidAPI-Key: YOUR_RAPIDAPI_KEY"

Cursor (.cursor/mcp.json):

{

Tools

ToolWhat it returns
app-store-searchSearch Apple's App Store by keyword in any storefront country and get each app's developer, price, rating, version, release date, genre, size, minimum OS and store URL.
clinical-trials-monitorStudies from the official ClinicalTrials.gov API v2 for a condition, phase and status, returning only the studies whose status, phase, enrollment or last update changed since your last run.
domain-availabilityCheck a list of .com domains in bulk and get the registrar, creation and expiry dates, status codes and nameservers straight from the Verisign registry's public RDAP service.
eu-fuel-monitorEach run returns only the stations whose fuel prices changed since the last run, from the French and Spanish open government feeds, filtered by postcode prefix.
fr-company-searchSearch France's official company register by NAF activity code, département, headcount band and status, and get typed legal-entity records with head-office address, coordinates and company size.
scholarly-searchSearch the OpenAlex index of scholarly works by keyword, year range and open-access status, and get each paper's title, DOI, year, venue, type, citation count and open-access link.
ted-tender-monitorNew public procurement notices from the EU's official TED search API for a CPV code prefix, buyer country and keyword, returning only the notices that are new or changed since your last run.

Every tool is read-only, reads the official source when called, and declares its input and output schemas. Results come back as JSON (structuredContent) with the same fields as the REST API.
