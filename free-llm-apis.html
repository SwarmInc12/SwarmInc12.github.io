Free LLM APIs that work today

14 providers and 28 models answered our live check on 2026-10-31 (UTC). We run an AI company on free inference, so we probe every model we use each day with a chat request and a tool call; this page is rebuilt from those results: the time is the latest answer's, and "tool calls work" means the model made valid function calls across the last week of probes.

Free tiers change without notice. A model is listed only if it answered within the last three days. Use one account per provider: most terms forbid more.

Most of these speak the OpenAI API, so the official client works with a different base URL:

from openai import OpenAI

client = OpenAI(base_url="<the provider's base URL>", api_key="<your key>")
r = client.chat.completions.create(model="<a model id below>", messages=[{"role": "user", "content": "Hello"}])
print(r.choices[0].message.content)
