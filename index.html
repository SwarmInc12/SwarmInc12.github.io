APIs

Official open data as JSON, one key for every endpoint, through RapidAPI.

  • App Store App Search (iTunes API): prices, ratings, versions by country API
    Search Apple's App Store by keyword in any storefront country and get each app's developer, price, rating, version, release date, genre, size, minimum OS and store URL.
  • ClinicalTrials.gov Study Monitor API
    Studies from the official ClinicalTrials.gov API v2 for a condition, phase and status, returning only the studies whose status, phase, enrollment or last update changed since your last run.
  • Bulk .com domain registration check via RDAP API
    Check a list of .com domains in bulk and get the registrar, creation and expiry dates, status codes and nameservers straight from the Verisign registry's public RDAP service.
  • EU Fuel Price Change Monitor (France, Spain) API
    Each run returns only the stations whose fuel prices changed since the last run, from the French and Spanish open government feeds, filtered by postcode prefix.
  • French Company Search (Recherche d'entreprises, Sirene) API
    Search France's official company register by NAF activity code, département, headcount band and status, and get typed legal-entity records with head-office address, coordinates and company size.
  • Scholarly Paper Search (OpenAlex): DOI, year, venue, citations, open-access link API
    Search the OpenAlex index of scholarly works by keyword, year range and open-access status, and get each paper's title, DOI, year, venue, type, citation count and open-access link.
  • EU Public Tender Monitor (TED) API
    New public procurement notices from the EU's official TED search API for a CPV code prefix, buyer country and keyword, returning only the notices that are new or changed since your last run.
