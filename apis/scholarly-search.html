Scholarly Paper Search (OpenAlex): DOI, year, venue, citations, open-access link API

Search the OpenAlex index of scholarly works by keyword, year range and open-access status, and get each paper's title, DOI, year, venue, type, citation count and open-access link.

No personal dataRead from the source at call time12 fields a resultfilter by query, year_from, year_to

Source: OpenAlex, under CC0. Every answer carries this attribution in its sources field.

Free plan

Free plan: 500 calls a month. Paid from $8.99 a month. Billed by RapidAPI; no card for the free plan.

Get a key on RapidAPI

One call:

curl -G "https://scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com/v1/scholarly-search" \
  --data-urlencode 'query=graph neural networks' \
  --data-urlencode year_from=2020 \
  -H "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  -H "X-RapidAPI-Host: scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com"

Answers {"product", "count", "items", "fetched_at"}; reads api.openalex.org when you call.

Parameters

ParameterTypeWhat it doesExample
querystringKeywords to search for in titles, abstracts and full text."graph neural networks"
year_fromintegerFirst publication year to include.2020
year_tointegerLast publication year to include.2026
oa_statusstringKeep only works with this open-access status (empty: all works). One of: , gold, green, hybrid, bronze, diamond, closed."green"
limitintegerAt most this many results (1–1000, default 100).20

Call it

With curl:

curl -G "https://scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com/v1/scholarly-search" \
  --data-urlencode 'query=graph neural networks' \
  --data-urlencode year_from=2020 \
  --data-urlencode year_to=2026 \
  --data-urlencode oa_status=green \
  --data-urlencode limit=20 \
  -H "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  -H "X-RapidAPI-Host: scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com"

With Python (pip install requests):

import os, requests

r = requests.get(
    "https://scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com/v1/scholarly-search",
    params={'query': 'graph neural networks',
 'year_from': 2020,
 'year_to': 2026,
 'oa_status': 'green',
 'limit': 20},
    headers={"X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"], "X-RapidAPI-Host": "scholarly-paper-search-api-openalex-doi-citations.p.rapidapi.com"},
    timeout=120,
)
for item in r.json()["items"]:
    print(item)

Questions

What does it cost? Free plan: 500 calls a month. Paid from $8.99 a month.

How fresh is it? Each call reads the official source then; an identical query within 15 minutes is answered from a cache.

Data last read 13 Nov 2026; the company's freshness target: 7 days (a search or lookup, read at call time; late after 7 days 6 h) — on time.

What if the source is down? The answer says so: a 502, or "partial": true when only some of its requests failed. Whether it is down now: the status page.

Can a field change? Yes, without notice: this API doesn't record its changes yet, and the OpenAPI document is the contract as it stands today. How changes are announced.
