Internet Archive Search Scraper API

Search the Internet Archive's catalog of free books, movies, audio, software and web items and get one row per item with its identifier, title, media type, download count and date added.

No personal dataRead from the source at call time5 fields a resultfilter by query

Source: Internet Archive (archive.org: item search and metadata), under the Internet Archive's Terms of Use. Every answer carries this attribution in its sources field.

Call it

With curl:

curl -G "https://internet-archive-search-api-books-movies-audio-software.p.rapidapi.com/v1/internet-archive" \
  --data-urlencode query=collection:prelinger \
  --data-urlencode limit=20 \
  -H "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  -H "X-RapidAPI-Host: internet-archive-search-api-books-movies-audio-software.p.rapidapi.com"

With Python (pip install requests):

import os, requests

r = requests.get(
    "https://internet-archive-search-api-books-movies-audio-software.p.rapidapi.com/v1/internet-archive",
    params={'query': 'collection:prelinger', 'limit': 20},
    headers={"X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"], "X-RapidAPI-Host": "internet-archive-search-api-books-movies-audio-software.p.rapidapi.com"},
    timeout=120,
)
for item in r.json()["items"]:
    print(item)

Questions

What does it cost? Free plan: 500 calls a month. Paid from $8.99 a month.

How fresh is it? Each call reads the official source then; an identical query within 15 minutes is answered from a cache.

Data last read 13 Nov 2026; the company's freshness target: 7 days (a search or lookup, read at call time; late after 7 days 6 h) — on time.

What if the source is down? The answer says so: a 502, or "partial": true when only some of its requests failed. Whether it is down now: the status page.

Can a field change? Yes, without notice: this API doesn't record its changes yet, and the OpenAPI document is the contract as it stands today. How changes are announced.
