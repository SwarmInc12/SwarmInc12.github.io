App Store App Search (iTunes API): prices, ratings, versions by country API

Search Apple's App Store by keyword in any storefront country and get each app's developer, price, rating, version, release date, genre, size, minimum OS and store URL.

Read from the official source when you call (itunes.apple.com); no personal data. GET /v1/app-store-search answers {"product", "count", "items", "fetched_at"}.

Source: Apple Search API (iTunes Search and Lookup), under Apple's Search API terms (Promo Content). Every answer carries this attribution in its sources field.

Get a key on RapidAPI  plans and pricing are on the listing; one key covers every endpoint.

Parameters

ParameterTypeWhat it doesExample
termstringKeyword to search for in the App Store (for example budget, photo editor, meditation)."budget"
countrystringTwo-letter App Store country code, which sets the prices, currency and ratings returned. One of: us, gb, ca, au, nz, ie, fr, de, es, it, pt, nl, be, at, ch, se, no, dk, fi, pl, cz, tr, gr, jp, kr, cn, hk, tw, sg, in, id, th, vn, ph, my, br, mx, ar, cl, co, za, ae, sa, il, eg, ng, ua, ro, hu."us"
limitintegerHow many apps to return (Apple allows up to 200 per search).50

Call it

With curl:

curl -G "https://app-store-search-api-itunes-prices-ratings-49-countries.p.rapidapi.com/v1/app-store-search" \
  --data-urlencode term=budget \
  --data-urlencode country=us \
  --data-urlencode limit=50 \
  -H "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  -H "X-RapidAPI-Host: app-store-search-api-itunes-prices-ratings-49-countries.p.rapidapi.com"

With Python (pip install requests):

import os, requests

r = requests.get(
    "https://app-store-search-api-itunes-prices-ratings-49-countries.p.rapidapi.com/v1/app-store-search",
    params={'term': 'budget', 'country': 'us', 'limit': 50},
    headers={"X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"], "X-RapidAPI-Host": "app-store-search-api-itunes-prices-ratings-49-countries.p.rapidapi.com"},
    timeout=120,
)
for item in r.json()["items"]:
    print(item)

Questions

How fresh is it? Each call reads the official source then; an identical query within 15 minutes is answered from a cache.

What if the source is down? The answer says so: a 502, or "partial": true when only some of its requests failed.
