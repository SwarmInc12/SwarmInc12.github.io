Bulk .com domain registration check via RDAP API

Check a list of .com domains in bulk and get the registrar, creation and expiry dates, status codes and nameservers straight from the Verisign registry's public RDAP service.

Read from the official source when you call (rdap.verisign.com); no personal data. GET /v1/domain-availability answers {"product", "count", "items", "fetched_at"}.

Source: Verisign RDAP (.com and .net registration data), under Verisign's RDAP terms of service. Every answer carries this attribution in its sources field.

Get a key on RapidAPI  plans and pricing are on the listing; one key covers every endpoint.

Parameters

ParameterTypeWhat it doesExample
domainsarrayRegistered .com domain names to look up, e.g. ["example.com", "google.com"]. A name the registry does not know (available) returns a 404 and no row.["example.com", "google.com", "apify.com"]
limitintegerAt most this many results (1–1000, default 100).20

Call it

With curl:

curl -G "https://domain-availability-api-com-bulk-rdap-lookup.p.rapidapi.com/v1/domain-availability" \
  --data-urlencode domains=example.com,google.com,apify.com \
  --data-urlencode limit=20 \
  -H "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  -H "X-RapidAPI-Host: domain-availability-api-com-bulk-rdap-lookup.p.rapidapi.com"

With Python (pip install requests):

import os, requests

r = requests.get(
    "https://domain-availability-api-com-bulk-rdap-lookup.p.rapidapi.com/v1/domain-availability",
    params={'domains': 'example.com,google.com,apify.com', 'limit': 20},
    headers={"X-RapidAPI-Key": os.environ["RAPIDAPI_KEY"], "X-RapidAPI-Host": "domain-availability-api-com-bulk-rdap-lookup.p.rapidapi.com"},
    timeout=120,
)
for item in r.json()["items"]:
    print(item)

Questions

How fresh is it? Each call reads the official source then; an identical query within 15 minutes is answered from a cache.

What if the source is down? The answer says so: a 502, or "partial": true when only some of its requests failed.
